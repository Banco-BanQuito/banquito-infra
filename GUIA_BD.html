¿Una BD por micro o una BD general?

Respuesta corta: Una base de datos por microservicio, pero dentro de un solo contenedor de PostgreSQL y un solo contenedor de MongoDB.

Cada micro tiene su propio espacio separado. Nadie ve ni toca los datos del otro.

Cómo se ve la arquitectura

Piénsenlo como dos edificios de apartamentos. Anahy levanta los edificios. Cada uno vive en su apartamento.

🍃   MongoDB — localhost:27017

ℹ️ Las bases de datos de PostgreSQL se crean automáticamente al levantar Docker (via el script db/init-postgres.sql). Las de MongoDB se crean solas cuando tu microservicio arranca por primera vez. No tienes que hacer nada manualmente.

Pasos para empezar a trabajar

  1. Clonar banquito-infra (solo una vez)

    git clone https://github.com/Banco-BanQuito/banquito-infra.git
cd banquito-infra

  2. Levantar la infraestructura con Docker

    Solo necesitas este comando. Levanta PostgreSQL, MongoDB y RabbitMQ.

    docker-compose up -d postgres mongo rabbitmq

    Verifica que todo esté corriendo:

    docker-compose ps

  3. Copiar tu application.properties

    En el repo banquito-infra, dentro de templates/, está el archivo listo para tu servicio. Cópialo a src/main/resources/application.properties de tu proyecto.

    # Ejemplo para Oscar:
cp banquito-infra/templates/application-oscar.properties \
   banquito-account-core-service/src/main/resources/application.properties

  4. Correr tu microservicio desde IntelliJ / VS Code

    Simplemente dale Run/Play a tu aplicación Spring Boot normalmente. Hibernate creará las tablas automáticamente en tu base de datos.

    ✅ El application.properties ya tiene localhost:5432 como valor por defecto. No hay que cambiar nada.

Preguntas frecuentes

❓
¿Tengo que instalar PostgreSQL o MongoDB en mi computadora?
No. Docker lo maneja todo. Solo necesitas Docker Desktop instalado.
❓
¿Tengo que crear las tablas manualmente?
No. Hibernate crea las tablas automáticamente cuando arrancas tu microservicio gracias a spring.jpa.hibernate.ddl-auto=update.
❓
¿Puedo ver los datos de mi base de datos?
Sí. Puedes usar DBeaver o TablePlus para PostgreSQL, y MongoDB Compass para MongoDB. Conéctate a localhost:5432 o localhost:27017 con usuario banquito y contraseña banquito123.
❓
¿Qué pasa si borro Docker y empiezo de cero?
Corre docker-compose down -v para borrar todo. Luego docker-compose up -d postgres mongo rabbitmq para empezar limpio.
